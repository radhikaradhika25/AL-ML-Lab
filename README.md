# AI-ML Lab

## Lab Exercise 1: Data Pre-processing Using Jupyter Notebook



The objective of this experiment is to perform data preprocessing on a real-world dataset using Python and Jupyter Notebook. Data preprocessing improves the quality of data before applying machine learning algorithms.

---

## Dataset

**Dataset Name:** Netflix Titles Dataset

The dataset contains information about Netflix movies and TV shows, including:
- Show ID
- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre
- Description

---

## Software & Libraries Used

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn (SMOTE)

---

## Preprocessing Steps Performed

1. Loaded the dataset using Pandas.
2. Displayed basic dataset information.
3. Identified rows, columns, data types, and missing values.
4. Displayed first, last, and random records.
5. Handled missing values using appropriate techniques.
6. Checked and removed duplicate records.
7. Detected outliers using the IQR method.
8. Handled outliers using clipping.
9. Applied Label Encoding.
10. Applied One-Hot Encoding.
11. Applied Min-Max Normalization.
12. Applied Standardization (Z-score Scaling).
13. Performed feature selection using correlation analysis.
14. Generated a correlation matrix and heatmap.
15. Created new features using feature engineering.
16. Converted data types where necessary.
17. Cleaned inconsistent and noisy data.
18. Split the dataset into training and testing sets.
19. Balanced the training dataset using SMOTE.
20. Compared the dataset before and after preprocessing.
21. Saved the cleaned dataset as a new CSV file.

The Netflix Titles dataset was successfully preprocessed using Python. The dataset is now clean, consistent, and ready for machine learning and data analysis.
